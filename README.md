# THM-Write-Ups
Markdown Write-Ups of TryHackMe rooms

## The Catalyst
I first found out about TryHackMe - or OSINT and CTF in general - by a Youtube video named *'I took an "entry level" CIA test'* by *Bog (@bogxd)*, that covered the OhSINT room. It seemed like a scavenger hunt game, using hidden file data and deep research, and I could not be more intrigued to search up THM and try these rooms on my own.

## Directories Guide
In the *Challenges-CTF* folder, there are three folders; *1-Easy*, *2-Medium*, *3-Hard*, and *4-Insane*. Inside each folder, there will be Markdown files with the title format ***YYMMDD-NAME.md***. The date represents when I completed this room, and the NAME is the original title of the room.
