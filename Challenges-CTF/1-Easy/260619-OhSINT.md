### A. Fetching Metadata
For this, I used **[ExifTool](https://exiftool.org/)** via macOS zsh installation. This program is available for Windows, macOS, and Linux environments. If you don't feel like installing software, you may also use online image metadata tools.  

#### - Method 1: ExifTool Manual Redirect (Recommended)
- First, you can manually navigate to the directory where your file is in.  For example, you can start by typing in:

<sub>Mac/Linux zsh</sub>
```bash title="Mac/Linux zsh"
cd /Users/(USERNAME)/Downloads
```
<sub>Windows CMD</sub>

```cmd
cd C:\Users\(USERNAME)\Downloads
```
- Once the terminal redirects to that directory where you have your image on, you can simply type

<sub>All Platforms</sub>
```bash
exiftool WindowsXP_1551719014755.jpg
```

#### - Method 2: ExifTool Drag and Drop (Faster!)
- The method I used to run ExifTool in *bash/zsh (Mac and Linux)*, is to open up the terminal app, and type in

<sub>Mac/Linux zsh</sub>
```bash
exiftool #with a whitespace!
```
- But don't press enter yet. You will drag and drop the image into the terminal window. This will automatically input the full path for you. the final input should look something like this:

<sub>Mac/Linux zsh</sub>
```bash
exiftool /Users/(USERNAME)/Downloads/WindowsXP_1551719014755.jpg
```

***Tip:** Change (USERNAME) to your computer's local user name.*

#### - Method 3: Online Tools
- Websites like **[Jimpl](https://jimpl.com/)**, **[EXIF.tools](https://exif.tools/)**, or **[METADATA2GO](https://www.metadata2go.com/view-metadata)** can extract the image's metadata by just dragging and dropping into the entire webpage or the space provided.

## 3. What is the SSID of the WAP he connected to?
>***Answer: ```UnileverWiFi```***  
*❌ Not Solved | Easy, Broken Solution*

There seems a lot to uncover in this sentence, but it is asking something much simpler than it looks.

* A ***WAP (Wireless Access Point)*** is a hardware that converts wired internet cables to wireless WiFi signals - one of the things that your home WiFi router does, to allow your phones, computers, and anything that supports WiFi to connect to the internet.

* An ***SSID (Service Set IDentifier)*** is the readable name of your WAP that you normally see when looking for WiFi. Names like **```xfinitywifi```** or **```Verizon_000000```** are common examples of SSIDs.

So, the question can be simplified as:  
***What is the name of his WiFi?***

### A. The Weird Twitter Post

If you scroll down through ```OWoodflint```'s Twitter profile, you will see this Twitter Post:

> ### <img src="https://pbs.twimg.com/profile_images/1102230646582325250/1AfGSBGl_400x400.png" width="20"> 0x00000000000000000000 
> @OWoodflint  
> From my house I can get free wifi ;D
>
> Bssid: B4:5D:50:AA:86:41 - Go nuts!  
> ###### 10:53 AM · Mar 3, 2019

```Bssid: B4:5D:50:AA:86:41```  
There is a new but familiar word here,  
**a BSSID.**  
You may be wondering, is that the SSID that the question was asking?

The short answer is **No, but you are pretty close.**  
A ***BSSID (Basic Service Set Identifier)*** is the *unique identifier* address of the specific WAP.

For example, there are lots of people named 'John Smith' out there, but having the same legal name doesn't make each of them the same person. Every 'John Smith' has a different Social Security Number, so they can be identified uniquely.  
**This is how BSSIDs work -** *they are just like a Social Security Number for a WAP.* There can be multiple WAPs with the same SSIDs, but no two WAPs can normally have the same BSSID.

***ℹ️ Note 2:** There are notable exceptions like Virtual Access Point Cloning, Enterprise Seamless Roaming (802.11r), and Spoofing.*

### B. WiGLE
To find the actual name of the WiFi with the BSSID, you will need a wireless network database website like **[WiGLE](https://wigle.net/)** to search find the corresponding SSID.

***❗️IMPORTANT:** As of the time solving this room and creating this write-up, WiGLE has repeatedly been returning 'PLOT ERROR', 'DAILY LIMIT', and 'search failed: too many queries today' on both Free Net and Advanced Search features, despite attempting across different calendar days, devices, and accounts. Because of this, I had to verify the intended solution through **[a different user's walkthrough.](https://www.youtube.com/watch?v=kLntZF5oD8g)***

#### -Method 1. Free Net Search (No Sign In)
- As you enter the WiGLE website, you will see a map covered in purple, red, and yellow dots. At the right side of these, there are input sections that allow Latitude, Longitude, SSID, and BSSID. Paste OWoodflint's BSSID ```B4:5D:50:AA:86:41``` to the ***BSSID section***, and click ***Filter***.
- Once the search is complete, zoom out from the current position, and find a specific point labled by a purple target symbol. **This should be located somewhere in the middle of London, UK.**

#### -Method 2. Advanced Search (More Stable, Recommended)
***Tip:** You have to sign in to use this feature.*  
- Locate to the top left options of the website, and click on the ***View*** button with a red magnifying glass icon. Click the second option, ***Advanced Search***.
- Click on the **General Search** section. At the right side of the screen where it says **Network Characteristics**, paste OWoodflint's BSSID ```B4:5D:50:AA:86:41``` to the ***BSSID/MAC:***, and click ***Query***.

### My Solution: Awkward Line Spacing
Looking closely on the WordPress page, I noticed that there is a large line spacing between the 'Im in New York right now...' sentence and the writer information and action options.

> # Author: owoodflint
> &emsp;
> # Hey
> Im in New York right now, so I will update this site right away with new photos!

### Original Solution: Source Code

To access the source code, you have 3 ways:

#### 1. F12
- On most browsers, pressing ```F12``` will open a window on the right side of the screen, with options like *Elements, Console, Sources, Network,* etc. You may stay at the *Elements* tab.

#### 2. Right Click
- Right click on any part of the webpage and select one of the last two options: *View Page Source* or *Inspect*. *View Page Source* will open a new tab with the page source code, and *Inspect* will display the same window as the F12 method.

#### 3.Keyboard Shortcut
- Pressing ```Ctrl + U``` (Windows) or ```Cmd + Option + U``` (Mac) will also open the page source code window.

#### 4. URL Edit
- Add ```view-source:``` at the front of the URL, and it will take yu to the page source code window.
